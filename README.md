# AI-Powered Mock Interview Preparation Portal

A complete multi-service web application built with React.js, Spring Boot, and MySQL.

## Tech Stack
- **Frontend:** React.js (JSX) + Tailwind CSS + npm
- **Backend:** Java 17 + Spring Boot 3.x + Spring Security + JWT
- **Database:** MySQL 8.0
- **AI:** OpenAI GPT API integration
